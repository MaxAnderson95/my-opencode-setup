This copy originates from R44VC0RP's plugin collection and preserves the local version used by Max. Max explicitly selected it for maintenance in this repository.

https://github.com/R44VC0RP/plugins/tree/main/packages/session-rename

Install `github:MaxAnderson95/my-opencode-setup#plugin-session-rename`. Publish source changes through `scripts/publish-plugins.sh`, then update the configured package in OpenCode.
